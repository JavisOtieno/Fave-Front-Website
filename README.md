# Fave Front Website

The public-facing marketing website for **Fave Promotions** — an affiliate e-commerce platform that helps people in Kenya start and run online businesses by promoting products without holding inventory.

[![PHP](https://img.shields.io/badge/PHP-Frontend-777BB4?style=flat&logo=php)](https://php.net)
[![CSS](https://img.shields.io/badge/CSS-Custom-1572B6?style=flat&logo=css3)](https://developer.mozilla.org/en-US/docs/Web/CSS)

## Overview

**Fave Front Website** is a lightweight, PHP-based static/marketing site that introduces the Fave affiliate program. It explains how promoters can:

- Sign up and get their own personalized online store
- Promote products to customers
- Earn commissions while the platform handles inventory, delivery, and payments

The site serves as the entry point for new affiliates and links to the admin/signup area.

## Tech Stack

- **Backend/Logic:** PHP (includes for header/footer)
- **Frontend:** HTML5, Custom CSS, JavaScript
- **Assets:** Separate folders for CSS, JS, images, and fonts
- **Server:** Compatible with Apache (`.htaccess` included)
- **SEO:** Meta tags, sitemap.xml, Google verification
